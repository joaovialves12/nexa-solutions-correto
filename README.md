# Sistema de Chamados — Nexa Solutions

Projeto para a disciplina de Manutenção e Evolução de Software.

## Contexto

A Nexa Solutions possui um sistema interno para abertura e acompanhamento de chamados de suporte. O projeto possui uma API REST desenvolvida em Django REST Framework e uma interface HTML simples para consulta e cadastro de chamados.

## Tecnologias

- Python 3.12 / Django 5.2
- Django REST Framework
- PostgreSQL 15 (Alpine)
- Docker & Docker Compose
- Git
